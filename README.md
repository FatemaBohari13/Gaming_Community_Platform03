# 🎮 GameHub – Gaming Community Platform

## 📌 Project Overview

GameHub is a modern and responsive gaming community platform designed to help gamers discover games, connect with friends, join gaming communities, participate in tournaments, and explore gaming content.

The platform provides a clean and interactive interface for viewing featured games, trending communities, tournaments, gaming news, chats, user profiles, and account settings.

## 🚀 Key Features

* Welcome and Landing interface
* Login and Sign Up interface
* Gaming Dashboard
* Featured Games
* Game Details
* Trending Gaming Communities
* Community Search and Filtering
* Community Discussions
* Create Post interface
* Like, Comment and Share interactions
* Tournament Management interface
* Live Tournament section
* Gaming Chat interface
* Online Friends
* User Profile
* Favorite Games
* Gaming Badges
* Friends and Communities
* Gaming News
* Recommended Friends
* Global Navigation
* Settings and Profile Management
* Notification Settings
* Theme Settings
* Privacy and Security interface
* Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Grid
* CSS Flexbox
* Responsive Web Design
